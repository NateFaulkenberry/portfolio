### Code Challenge Platform

A lightweight browser-based coding challenge platform built to demonstrate modern front-end engineering, problem-solving, and software design skills. The application provides a curated set of daily programming challenges with an in-browser editor, automated test execution, solution validation, progress tracking, and persistent local state.

The project is designed as a practical demonstration of production-oriented development, including component architecture, state management, testable business logic, responsive UI design, client-side persistence, error handling, and automated challenge evaluation. Built as a static application suitable for GitHub Pages, with an emphasis on clean TypeScript, maintainable architecture, and minimal infrastructure.
